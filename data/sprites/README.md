# Sprites fournis par l'utilisateur

Isaac Codex ne redistribue **aucune** image du jeu : les emblèmes affichés sont générés automatiquement.

Si vous disposez légalement d'images (par exemple extraites de votre propre copie du jeu pour un usage personnel, ou d'un pack dont la licence autorise la redistribution), placez-les ici :

```
data/sprites/items/<id>.png         ex. data/sprites/items/105.png
data/sprites/trinkets/<id>.png
data/sprites/consumables/<slug>.png
data/sprites/characters/<slug>.png  ex. data/sprites/characters/isaac.png
data/sprites/bosses/<slug>.png
```

Formats acceptés : png, webp, gif. Les noms ne peuvent contenir que des lettres, chiffres et tirets. Les images sont détectées automatiquement (cache d'une minute), sans redémarrage.

Vous restez responsable du respect des droits d'auteur sur les images que vous ajoutez, en particulier sur une instance publique.
